3D models to scale, built and filmed from code.

craft3d is three commands for Claude Code. Give it a photo, a spec or an idea and it builds the object in three.js at real dimensions, with every moving part driven by its real mechanism. Then it measures and photographs its own work before calling it done. The car above was built from the FIA 2026 rulebook, and the film is 120 lines of code.

The three commands

/3d-model

Realistic: shaded paint, metal, glass and rubber, clean or worn, at real dimensions with working mechanisms.

/wireframe

The same model as a technical illustration: section cuts, exploded views, blueprints.

/cinematic

Films it or shoots it as a product photograph, with real soft shadows, depth of field and motion blur.

Install

# in Claude Code
/plugin marketplace add yesith0106/craft3d
/plugin install craft3d@craft3d

Or clone it and link the commands yourself: see the README.
